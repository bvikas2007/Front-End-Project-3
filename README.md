# 💰 Pricing Comparison Table

A simple HTML project that displays a pricing comparison table for three subscription plans: **Basic**, **Pro**, and **Premium**. The project focuses on using semantic HTML and accessible table structures without relying on external CSS.

## 📌 Features

- Semantic HTML5 structure using:
  - `<header>`
  - `<main>`
  - `<footer>`
- Comparison table built with:
  - `<table>`
  - `<caption>`
  - `<thead>`
  - `<tbody>`
- Accessible table headers using:
  - `scope="col"`
  - `scope="row"`
- Merged table header using `colspan`
- Responsive page metadata:
  - `meta charset`
  - `meta viewport`
- Simple handwritten-style font for better readability
